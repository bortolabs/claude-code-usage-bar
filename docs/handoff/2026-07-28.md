## Contexto importante
- **O Extension Development Host não sobe nesta máquina** por linha de comando: o `code` CLI
  é interceptado pelo `VSCODE_IPC_HOOK_CLI` do terminal integrado, e mesmo via `open -n` +
  Terminal.app o VS Code sai sem abrir janela enquanto a instância principal existe
  (`--user-data-dir` isolado não vinga). Para validar UI, ou é **F5** na própria janela, ou
  se testa na **extensão instalada** — foi o que se fez aqui (mesmo código do timeout).
- **Testar o AI advice com Ollama leva 5min**: `aiAdviceApiStyle: openai`, endpoint
  `http://127.0.0.1:11434/v1/chat/completions`, modelo `qwen2.5:7b`. A chave exigida pode ser
  qualquer string — o Ollama ignora o Bearer. Para exercitar o timeout, um servidor que
  segura o socket >120s prova o que o modelo real não prova (ele responde rápido demais).
- O `globalState` real da extensão fica em
  `~/Library/Application Support/Code/User/globalStorage/state.vscdb` (tabela `ItemTable`,
  chave `bortolabs.claude-code-usage-bar`) — dá para auditar o que a extensão gravou sem UI.
