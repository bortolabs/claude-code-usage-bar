- **`force` não fura o `updateCheckEnabled`** — desligar é opt-out explícito de rede (regra 1 do
  CLAUDE.md); o comando responde dizendo isso em vez de chamar a rede assim mesmo.
- **`dashboardWindow` e `costWindow` NÃO entram na aba Config** (o ROADMAP pedia): são estado do
  seletor de janela que já existe na UI — virariam dois controles para o mesmo valor. Viraram

  mudou é ela não ser mais obrigatória. Sem chave, **nenhum** header de auth — `Bearer ` vazio
  faz servidor estrito responder 401.
